# Placement Portal - Frontend

React frontend for the Placement Portal with separate Student and Placement Officer portals.

## Tech Stack
React, Vite, React Router, Axios

## Features
- Login / Register with JWT, role-based protected routes
- Student: dashboard, profile and skills, resume upload, job browsing with eligibility and skill-gap, apply, application tracking
- Officer: analytics dashboard, manage companies, jobs, students, update application status

## Setup
1. Start the backend (see `placement-portal-backend`) on port 8080
2. `npm install`
3. `npm run dev` (opens on http://localhost:5173)
